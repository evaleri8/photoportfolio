# by.erzhee — портфолио фотографа

Статический многостраничный сайт. Внутри — HTML, CSS, JavaScript и изображения. Не требуются сборщик, база данных или серверный код. Категории, проекты, обложки, фотографии и описания хранятся **в одном файле**.

## Быстрый старт

Распакуйте архив и откройте `index.html`. Для разработки удобнее пользоваться VS Code + Live Server (либо `python -m http.server 8000`). Сайт подходит и для GitHub Pages.

Шрифты Google Fonts загрузятся при наличии интернета; при отсутствии сети используется резервный шрифт. Фотографии из демонстрационной версии уже находятся в архиве.

## Самое важное: где добавлять категории и проекты

**Откройте `assets/js/projects.js`.**

В нём есть один основной массив `window.PORTFOLIO_CATEGORIES`. Каждая категория содержит список `projects`, а каждый проект — свой список фотографий `photos`.

Сейчас заданы четыре категории:

| ID | Название | Демонстрационные проекты |
| --- | --- | --- |
| `studio` | Студийная съёмка | «Лица» |
| `outdoor` | Выездная съёмка | «После полуночи» |
| `concerts` | Концерты | «Live Energy» |
| `events` | Мероприятия | Пока нет |

Это рабочая структура кода: проекты распределены по категориям как пример, вы можете переносить их между категориями и менять подписи.

### 1. Как добавить новую категорию

В `assets/js/projects.js` добавьте **ещё один объект** внутрь `window.PORTFOLIO_CATEGORIES`:

```js
{
  id: "family",
  title: "СЕМЕЙНЫЕ СЪЁМКИ",
  description: "Истории близких людей.",
  projects: [],
},
```

Остальное сделается **автоматически**:

- новая кнопка появится на странице `works.html`;
- рядом с названием отобразится количество проектов;
- при выборе категории посетитель увидит только её проекты;
- пока проектов нет, будет аккуратное сообщение;
- в разделе «Все проекты» по-прежнему будут доступны все работы.

Правила для `id`: короткое уникальное название латиницей, без пробелов. В дальнейшем лучше не менять его — он используется в ссылках.

### 2. Как добавить проект внутрь категории

Найдите нужную категорию и вставьте объект **внутрь её `projects: [ ... ]`**. Например:

```js
{
  id: "autumn-park",
  order: 4,
  title: "ОСЕННИЙ ПАРК",
  heading: ["ОСЕННИЙ", "ПАРК"],
  subtitle: "Прогулка в осеннем парке.",
  summary: "Тёплая история во время прогулки.",
  story: "Здесь можно написать историю съёмки и свои впечатления.",
  photos: [
    {
      src: "assets/images/autumn-01.jpg",
      alt: "Портрет в осеннем парке",
      position: "center",
    },
    {
      src: "assets/images/autumn-02.jpg",
      alt: "Деталь осенней прогулки",
      position: "60% center",
    },
  ],
},
```

Сами файлы фотографий сначала положите в `assets/images/`.

**После этого не нужно создавать HTML-страницу проекта или вручную добавлять карточку!** Карточка появится в разделе «Все проекты», в нужной категории и в череде коллажей главной. Отдельная страница откроется автоматически по адресу:

`project.html?id=autumn-park`

Все новые проекты используют **один шаблон** `project.html` + `assets/js/project-page.js`. Старые адреса `project-faces.html`, `project-live.html` и `project-night.html` оставлены для совместимости, но их содержимое тоже собирается из общего каталога.

### 3. Что означают поля проекта

| Поле | Где используется |
| --- | --- |
| `id` | Уникальный адрес проекта. Не повторяйте ID. |
| `order` | Порядок карточки в «Все проекты» и коллажа на главной. |
| `title` | Название карточки, подписи, следующего проекта. |
| `heading` | Крупный заголовок страницы; каждый элемент массива — отдельная строка. |
| `subtitle` | Короткий подзаголовок страницы проекта. |
| `summary` | Короткое описание в каталоге и метатег описания. |
| `story` | Текст «За кадром» на странице проекта. |
| `photos` | Фотографии: **первая — обложка**, остальные добавляются в галерею. |
| `grayscale: true` | Необязательное поле для чёрно-белой обложки. |
| `url` | Необязательно. У трёх старых проектов указано для сохранения прежних адресов; новым не нужно. |

В каждом фото `src` — путь к файлу, `alt` — альтернативное описание фотографии, `position` — смещение при кадрировании (`center`, `70% center`, `center top` и т. д.). Для одного проекта можно указать сколько угодно снимков.

### 4. Как поменять категорию уже существующего проекта

Переместите целый объект проекта из массива `projects` одной категории в массив `projects` другой. **Не нужно изменять фильтры, HTML или ссылки**: принадлежность будет рассчитана автоматически.

## Фильтр по ссылке

Выбранную категорию можно открыть сразу:

- `works.html` — все работы;
- `works.html?category=studio` — студийные съёмки;
- `works.html?category=outdoor` — выездные;
- `works.html?category=concerts` — концерты;
- `works.html?category=events` — мероприятия.

При добавлении новой категории подставьте её `id` в параметр `category`.

## Как ведут себя коллажи

- 1 снимок: одиночная фотография;
- 2 снимка: композиция из двух;
- 3 снимка: композиция из трёх;
- более 3 снимков: при открытии выбираются 3 уникальные фотографии;
- на телефоне (ширина до 600 px): **максимум 2 фотографии** в одном коллаже;
- смена проектов — раз в 6,5 секунды; доступно ручное перелистывание и пауза.

Коллажи берут данные из `projects.js` и не требуют отдельного списка. Удаление или добавление проекта отражается и на главной.

## Хедер

Логотип теперь выглядит как **`by • ERZHEE`** с крупной оранжевой точкой. Разметка хедера общая: `assets/js/header.js`, на всех страницах вызывается один и тот же файл. Размер точки задаётся в `assets/css/06-catalog.css` через `.brand-dot`.

## Остальное

Контактная форма по-прежнему **сохраняет бриф в TXT-файл на устройстве посетителя**, но не отправляет его фотографу. Чтобы принимать заявки, потребуется отдельно подключить почту или сервис форм.

Фотографии и описания в архиве демонстрационные. `hero.png` — сгенерированная иллюстрация, остальные изображения — из Unsplash, ссылки на первоисточники находятся в `ASSETS.md`. Перед публикацией замените примеры своими работами.

Сайт не требует установки зависимостей. Для публикации загрузите содержимое папки `raw-frame` в корень статического хостинга.

## Обновление: анимация by.erzhee и страница «Обсудить съёмку»

- **Приветственная анимация** в `assets/js/intro.js` теперь показывает `by • ERZHEE`, а не прежнее название. Анимация затвора сохранена. Проверка первого входа находится в `assets/js/intro-bootstrap.js`; оба файла используют один ключ `by-erzhee-shutter-v3`, поэтому новую заставку можно увидеть даже в уже открытой вкладке.
- **Страница `contact.html`** выполнена в спокойных графитовых, серо-зелёных и кремовых оттенках без ярко-оранжевого фона.
- Под формой располагается **интерактивная подборка фотографий**. Изначально выделено `by.erzhee` и показываются четыре случайные фотографии из общего каталога. При наведении мышью или переводе фокуса на категорию отображаются фотографии только этой категории. Нажатие на название закрепляет выбор (на смартфонах это основной способ переключения).
- Если в категории одна фотография, отображается одна; если две или три — соответствующее количество. Если фотографий ещё нет, появляется сообщение о будущих проектах, а не изображения из другой категории.
- **Добавлять слова и фотографии отдельно не требуется:** данные автоматически подтягиваются из `assets/js/projects.js`, включая новые категории. В этом же файле задаются изображения в `photos: []` для каждого проекта. Формат съёмки в брифе также формируется из этого списка.
